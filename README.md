# 🌿 EcoNest – Sustainable Living Website

EcoNest is a modern and responsive eco-friendly e-commerce website designed to encourage sustainable living. It provides users with an attractive platform to explore environmentally friendly products and learn about sustainable lifestyle choices.

## 🌱 About the Project

EcoNest focuses on making sustainable living simple, accessible, and practical. The website showcases eco-friendly products such as reusable water bottles, bamboo toothbrushes, eco tote bags, and plantable notebooks.

The project is built using **HTML5, CSS3, and JavaScript**, with a clean nature-inspired design, responsive layouts, interactive elements, and scroll animations.

## ✨ Features

* 🏠 Modern landing page with a sustainability-focused hero section
* 🛍️ Featured eco-friendly products
* 🏷️ Product categories:

## ⚙️ How to Run

1. Clone this repository:

```bash
git clone https://github.com/your-username/EcoNest.git
```

2. Open the project folder.

3. Open `index(2).html` in any modern web browser.

4. Explore the EcoNest website.

No backend server or database is required for the current version.

## 🛒 Add to Cart

The Add to Cart functionality is implemented using JavaScript. When a user clicks an Add to Cart button, the selected product is added to the cart count and a confirmation message is displayed.

The current implementation provides front-end interaction only and does not include a backend shopping cart or payment system.

## 📩 Contact Form

The contact form accepts:

* Name
* Email Address
* Message

JavaScript validates that all fields are completed and displays a confirmation message after submission. The current form does not send the message to a backend or email service.

## 📱 Responsive Design

EcoNest is designed to work across different screen sizes.

The layout adapts for:

* 💻 Desktop
* 📱 Mobile
* 📟 Tablet

On smaller screens, the navigation changes to a mobile menu and product/category grids adjust automatically.
